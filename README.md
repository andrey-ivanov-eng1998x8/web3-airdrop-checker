# web3-airdrop-checker

I manage a handful of wallets and got tired of clicking through a dozen claim UIs to check if anything was waiting. This scrapes the claim pages and reports back without touching a browser extension.

## install

pip install -r requirements.txt

## usage

Wallets and airdrops are cached in ~/.config/airdrop-checker/ so repeated runs don't hammer the sites.
